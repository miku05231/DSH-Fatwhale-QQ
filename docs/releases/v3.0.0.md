# QQ-DSH v3.0.0

新增群聊免唤醒判定、QQ 回复语音和 B站定时自动化。运行环境要求 Node.js 22+；源码运行无需 `npm install`，可选语音和浏览器登录态提取另需 Python 依赖。

## 新功能

- 群聊在原有白名单、黑名单和限流之后，根据本群近期消息和机器人回答判断是否接话。JEV URL 和 Token 均非空时使用 JEV，否则使用当前默认 DSH 模型；判定超时、异常或不明确时保持静默。私聊及明确 @ / 唤醒词沿用原会话流程。
- 系统页新增 JEV Base URL、Token、模型名、超时和上下文配置。Token 掩码输入，保存后不回传；留空保留已存凭据。
- 内置「回复语音」插件，首个 provider 为 Edge TTS。文字发送成功后通过 OneBot `record` 追加语音，失败保留文字，临时音频自动清理；不包含语音识别和翻译。
- 自动化页新增 B站 App 扫码登录、关键词搜索、UP 动态订阅、本地时间 5 字段 Cron、来源合并去重和 QQ 私聊 / 群摘要推送。浏览器导入作为备用方式，错误会区分数据库锁定与不支持的应用绑定加密。
- 支持动态评论和指定 UID @，使用当前 DSH 模型筛选相关性并生成正文。同一动态最多尝试一次，每日最多 3 次、间隔至少 30 分钟；平台拒绝、登录失效或状态不确定时停止发布，不自动重试。审计保留正文、动态、目标 UID、时间和结果。
- 语音、自动化和自动评论默认关闭；评论还要求显式开启并确认已完成人工验收。Cookie 留在本机，不返回前端或写入公开审计。
- README 增加实际前端渲染的新功能截图与配置说明；打包和公开导出排除本机验收记录，保留必要的第三方许可证。

## 安装与升级

Windows 用户下载完整的 `qq-bridge-3.0.0-portable-win64.zip`，或在控制台「系统 → 应用更新」检查并确认安装。源码用户可使用 `qq-bridge-3.0.0-source.zip`；单独 EXE 需要配合完整工程使用。附件 `SHA256SUMS.txt` 提供三个文件的 SHA-256。

更新保留配置、登录态、人格、记忆、表情库和工作区。升级后检查新增开关及配置；启用语音前执行 `python -m pip install -r tools/requirements-voice.txt`。旧版升级后的真实账号行为仍按上面的未实测范围进行小范围验收。
