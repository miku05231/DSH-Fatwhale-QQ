# QQ-DSH v0.2.8

- 缩小托盘右键“退出”菜单，保留提示、无障碍说明和退出确认。
- 后台状态查询异步初始化并复用工作池，避免慢查询阻塞托盘点击。
- 收起托盘溢出面板、点击菜单外或切换窗口时自动关闭菜单。
- Windows 独立 Git 源码目录支持控制台“系统 → 应用更新 → 安装并重启”，只安装官方稳定版标签，并保护本机数据。
- 源码安装暂不可用时仍显示安装按钮和具体原因。
- 修复首次切到手动模型时未提交供应商和模型的问题。
- EXE 测试等待隔离浏览器和托盘进程退出；超时结束测试进程树，清理失败保留原始诊断和测试报告。
- 测试使用隔离配置、临时人格与记忆、本地模型服务；真实 DSH 内核参与兼容性验证。

控制台右下角“系统”页面顶部提供“应用更新 → 检查更新”。有新版且安装条件满足时，可点击“安装并重启”。旧版源码安装需要先手动更新一次，才能使用源码更新功能。更新保留配置、人格、记忆、表情库及自定义工具。

v0.2.6 和 v0.2.7 标签保留；这两个版本未通过全部 Windows 发布检查，没有正式发行包。本版修复测试进程清理及失败诊断问题。

本机完整回归 52/52 组通过，使用固定 DSH 内核、本地模型及隔离浏览器。验证范围包括 Windows 深浅色与缩放、连续后台查询、查询阻塞及工作池初始化期间退出、前台窗口切换、模拟溢出面板隐藏，以及实际便携包的隔离安装。真实 QQ 收发、Docker、Electron 和实际 Explorer 托盘溢出面板不包含在自动回归中。
