# QQ-DSH v3.4.0

本版补齐群聊运营常用的功能：运行统计、群友可用的指令、关键词自动回复、每日群聊总结和按会话管理；插件改为跟随宿主 DSH 的内核版本，并且可以直接在 DSH 插件页更新。DSH bundle：qq-bridge-companion **0.4.0**。

## 新功能

- **运行统计**：概览页显示近 7／30 天收发趋势、成功率、平均耗时和今日活跃群／用户，数据存 `state/stats.json`，保留 30 天。原来不准的「今日消息」改成「今日请求 · 成功率」。
- **群友可用的指令**：`/帮助`、`/状态`、`/排行`、`/昨日排行`，不调模型、不碰电脑。`commands.enabled=false` 整组关闭，`commands.rank=false` 只关排行。
- **关键词自动回复**（「自动化」页）：关键词 → 固定文字或图片，支持包含、整句、正则，可限定群聊／私聊／指定群，每条规则有冷却。命中直接回，不排队、不调模型，群里不用 @。正则匹配有 50ms 上限，写坏的正则会被暂停，不会卡住桥接。
- **每日群聊总结**（「自动化」页，默认关闭）：每天到点用当前模型、不带任何工具，把各群当天的聊天写成几条要点并附发言排行。一轮全部失败会隔 10 分钟重试，当天最多 3 轮。管理员可在群里发 `/今日总结` 立刻生成。
- **会话管理**（「会话」页）：每个群／私聊一行，显示最后活跃时间、今日群发言和会话数，可单独切换人格、重置上下文。
- **日志**：按级别筛选、关键词搜索，自动滚动的选择会记住。
- **宽屏导航**：窗口 ≥1024px 时导航移到左侧竖排；手机和插件内嵌面板不变。

## 插件跟随宿主 DSH

作为 DSH 插件运行、`dsh.command` 保持默认（`dsh`／`auto`／留空）时，普通聊天、群聊判定、每日总结等不带工具的调用改用宿主自己的 `@deepseek-ai/dsh`：在 DSH Desktop 里用 Desktop 内置的内核，在 `dsh web` 里用启动它的那份安装。以前会去 PATH 里找另装的 npm 版，版本可能和宿主不一致。`dsh.command` 写具体路径时照旧固定使用那份。

- 兼容 Desktop 0.2.2 内置内核里改名的 `dsh-deepseek-account` 模块。
- 插件以独立进程拉起桥接时，通过环境变量继承同一个宿主。
- 插件清单的 DSH 版本范围放宽到 `>=0.2.0-rc.2 <0.3.0`。

## 在插件页更新

DSH 插件页新增一行版本信息和「检查更新」「安装」按钮，完整控制台的「系统」页也一样。

- **用 git 检出安装的插件**可以直接在插件页更新：拉取正式发布版本的代码（只做快进，本地有未提交修改时停止），配置、数据可以在程序目录外，不受影响。
- 插件模式下安装器**只更新文件**，不会停止进程，也不会拉起旧的托盘／独立桥接；装好后提示「重启 DSH 后生效」。
- 解压 source／便携包安装的插件会提示到发布页手动更新。

## 升级

- **已经用 git 检出安装的**：先在终端里 `git pull` 到本版（3.3.0 的更新器还不支持插件模式），从本版以后就可以在插件页更新。
- **解压安装的**：下载 `qq-bridge-3.4.0-source.zip` 覆盖程序文件，保留配置、`state`、记忆和工作区；或者改用 `git clone` 安装，以后在插件页更新。
- 升级后重启 DSH。新功能的设置都有默认值，旧配置不用改。

`qq-bridge-launcher-3.4.0.exe` 仍是旧托盘／独立服务部署的启动器，插件模式无需运行。

## 验证

- 新增关键词回复、会话管理、每日总结、宿主跟随和插件模式更新的测试；在 Windows 本机跑了相关旧测试、真实桥接 + 假 NapCat 的端到端测试，以及真实 PowerShell 安装器的插件模式更新。
- 用 DSH Desktop 自带的 0.2.2-rc.5 内核实际跑通普通聊天，并在真实 QQ 环境确认非管理员消息正常回复。
- 本版没有重新做 v3.3.0 那样的完整发布验证；上一次完整验证范围见 [v3.3.0 验证记录](v3.3.0-verification.md)。
