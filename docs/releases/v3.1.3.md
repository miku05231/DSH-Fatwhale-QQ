# QQ-DSH v3.1.3

修复命令行进程管理、配置文件选择、群成员准入和长时间运行时的限流记录清理。运行要求仍为 Node.js 22+。

## 修复

- CLI 的 `start`、`stop`、`restart` 和状态查询核对本安装的 Node 入口脚本。旧状态文件中的 PID 被其他程序复用时，不再将其视为桥接或控制台，也不再停止该无关进程。
- `--config` 支持自定义文件名及现有目录，并优先于 `QQ_CONFIG`；环境变量相对路径按进程工作目录解析，资源路径按实际配置文件目录解析。
- `privatePolicy="blacklist"` 只改变私聊准入。`allowGroupMembers=false` 时，非白名单群成员仍不能触发聊天，不改变显式管理员权限。
- 限流器每个时间窗口清理不再活跃的用户，保留活跃用户额度，避免长期累积过期记录和反复扫描所有用户。
- NapCat 健康检测工作线程不再继承父进程的测试入口参数，修复 `node --test` 下的 OneBot 回退检测失败。

## 验证与隐私

新增配置入口和安全限流回归检查，扩展群成员与 CLI 真实隔离进程测试；发布工作流在 Linux、Windows 上执行相关检查，并保留完整包装、导出及便携包安装检查。具体结果与边界见 [v3.1.3 验证说明](../verification-v3.1.3.md)。

一处旧测试中的来源未确认账号、昵称和现场描述已替换为合成数据。配置、Token、会话、日志、记忆和本机维护文件不属于本次上传及发行内容；这次检查不代表历史提交、旧附件或平台缓存均已清理。

未新增真实 QQ 文字、语音、平台发布、长期登录稳定性、Docker 或 macOS 验收。进程归属检查针对应用标准启动方式；无法确认归属时保守拒绝停止，使用额外 Node 参数或短路径启动的实例可能需要通过其原启动方式管理。

## 安装

Windows 下载 `qq-bridge-3.1.3-portable-win64.zip`，或在控制台“系统 → 应用更新”检查并确认升级。另提供源码包、独立启动器和 `SHA256SUMS.txt`；独立启动器需要完整工程配合运行。
