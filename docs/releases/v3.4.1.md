# QQ-DSH v3.4.1

控制台「插件」页的整理版本：插件卡片可以折叠，配置区排版更紧凑。DSH bundle：qq-bridge-companion **0.4.0**（未变化）。

## 改进

- **插件卡片可折叠**：AstrBot 插件和 DSH 插件的卡片默认收起，只显示名称、版本、一行说明和启用开关；点标题展开配置、来源信息和操作按钮。每个插件的展开状态记在本机浏览器里，刷新、保存配置后保持不变。
- **全部展开 / 全部收起**：「插件」页顶部新增两个按钮，一次切换所有插件卡片。
- **配置区排版更紧凑**：
  - 字段说明紧贴在对应输入框下方，不再因为同一行有更高的字段而被推到很远的位置。
  - 分组配置（如 `retrieval` 这类嵌套设置）占满整行，组内字段按宽度自动分栏。
  - 收窄了字段、按钮行和插件卡片之间的间距；「同时删除插件数据」改为和卸载按钮同一行的说明式勾选。
- 键盘可以用 Tab 选中插件标题，回车或空格展开收起；系统开启「减少动态效果」时不播放展开箭头动画。

## 升级

- **用 git 检出安装的插件**：在 DSH 插件页的 QQ 桥接面板里点「检查更新」→「安装 3.4.1」，装好后重启 DSH。
- **解压安装的**：下载 `qq-bridge-3.4.1-source.zip` 覆盖程序文件，保留配置、`state`、记忆和工作区。
- 没有新的设置项，旧配置不用改。

## 验证

- 新增插件折叠的单元测试（默认收起、记住展开状态、全部展开／收起、属性转义、浏览器存储不可用时退回内存）。
- 在真实浏览器里用示例数据检查了 1440px 和 375px 宽度下的展开、收起和刷新后保持状态，页面没有横向溢出；控制台、更新界面、平台和生图页面的既有浏览器测试全部通过。
- 发布前复查了 v3.4.0 的代码和发行说明：源码、示例和测试中只有占位用的 QQ 号与群号，没有真实账号、密钥、本机路径或聊天内容。
