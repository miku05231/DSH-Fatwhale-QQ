# QQ-DSH v3.2.1

v3.2.1 修复 Windows 启动入口，并修正隔离测试和 Docker 版本标识。AstrBot 继续默认关闭，运行时仍固定 AstrBot 4.29.3 / Python 3.12.10，生产 DSH 核心保持 0.2.0-rc.2。

- Windows EXE 复用原生 `-File` 引导入口，避免隐藏 PowerShell 的编码命令包装卡住；引导脚本明确使用 UTF-8 输出，保留 CLI、中文错误输出、隐藏引导与退出码。
- AstrBot 模型网关测试复用 DSH 路径解析，支持 `QQ_TEST_DSH_COMMAND`，不再依赖开发者的固定安装目录。
- 系统页浏览器测试在限定时间内等待实际 DOM 渲染，不再仅按固定延时判断加载失败。
- Docker 运行测试按实际插件清单核对加载结果，覆盖 ping 和回复语音插件。
- 常规和 NAS 镜像、Compose、AstrBot 应用清单统一为 3.2.1，并增加版本一致性检查。

本版使用临时配置、本地模型和协议夹具验证，不向真实 QQ 联系人发送消息。具体结果和未测试范围见 [v3.2.1 验证说明](https://github.com/miku05231/DSH-Fatwhale-QQ/blob/v3.2.1/docs/releases/v3.2.1-verification.md)。

从 v3.2.0 升级可使用完整便携包或控制台应用更新。更早版本的旧更新 helper 可能拒绝 runtime 文件，迁移边界沿用 [v3.2.0 说明](https://github.com/miku05231/DSH-Fatwhale-QQ/blob/v3.2.0/docs/releases/v3.2.0.md#便携更新兼容)。Docker 用户需重新构建镜像；不要使用 Windows EXE 更新容器。
