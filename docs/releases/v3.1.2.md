# QQ-DSH v3.1.2

本版包含 v3.1 的模型同步、QQ 登录检测和启动恢复修复，减少托盘状态探测的前台初始化工作，并修正 Windows 自动发行测试的环境差异。运行要求为 Node.js 22+。

## 模型与登录修复

- 连续多轮复用同一会话时，控制台保存的合法模型与思考档位在下一条 QQ 消息生效，已打开的 DSH 对话页同步显示选择；无需重建会话。
- 按模型能力校验思考档位，分别展示目标、实际、待应用与失败。显式选择失败时报告错误，在途任务和已接收任务不重复回退执行。
- 从实际持久事件记录模型回执，修复恢复会话和重复 header 的档位继承，不改桌面全局默认模型。
- 使用 NapCat WebUI 和已鉴权 OneBot 查询 QQ 实际状态，改进本安装进程识别、保存账号恢复、端口冲突处理及跨启动日志归档。
- 新增脱敏健康记录；原始 NapCat 日志及业务日志仍作为本机私有数据保管。保留本机配置、会话、人格、记忆和自定义工具。

## 托盘与发行修正

托盘状态探测池改用仅含 Core 命令的初始状态，避开旧工厂在前台创建完整运行配置的路径；继续在后台异步打开探测池并查询实际服务状态，保留一秒响应性检查。

v3.1.0、v3.1.1 的自动构建先后因 PowerShell 模块加载和托盘响应性检查被阻止，均未生成正式 Release；历史标签保留。测试子进程限制为对应 PowerShell 自带的模块目录，并统一临时目录的实际长路径。新增完整预检模式，执行全部测试、构建和实际便携包的隔离安装，通过后再创建正式版本标签。

## 验证范围

模型修复沿用真实隔离 Electron 24/24、DSH Web + Edge 19/19、companion 55/55 和独立宿主 13/13 的证据。Windows 进程控制本机与云端专项均 10/10 通过；本次托盘本机两组通过，其中外观、退出与响应性 201 项。Linux/Windows 完整云端预检通过，覆盖全部发布测试、四份资产构建与实际便携包隔离安装；本机 v3.1.2 包装 159 项、公开导出 111 项、实际包升级 66 项通过。具体证据与最终发布结果见 [v3.1.2 验证说明](../verification-v3.1.2.md) 和对应标签的 GitHub Actions。

真实 QQ 仅进行过只读在线检查及一次 NapCat 重启后的快速登录恢复。真实文字/语音投递、完整工作日、网络切换、休眠、用户注销恢复、本版 Docker 和其他系统尚未全部验收；登录身份失效的具体触发原因仍未确定，不承诺永久免重新授权。

## 安装与升级

Windows 用户下载 `qq-bridge-3.1.2-portable-win64.zip`，或在控制台“系统 → 应用更新”检查并确认安装。另有 `qq-bridge-3.1.2-source.zip`、`qq-bridge-launcher-3.1.2.exe` 和 `SHA256SUMS.txt`；独立 EXE 需要配合完整工程。

升级保留本机数据。任务空闲时正常退出并重启 DSH，以加载新的 companion；自动更新器不会终止 DSH。模型同步发生在下一条 QQ 消息提交时，保存操作不立即修改所有打开的桌面对话。
