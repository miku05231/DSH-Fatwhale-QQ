# QQ-DSH v0.2.6

- 缩小托盘右键「退出」菜单，保留完整的无障碍说明、提示和退出确认。
- 状态探测移到后台，进程或 HTTP 查询缓慢时仍可及时点击托盘菜单。
- 托盘弹层收起、点击菜单外或切换窗口时自动关闭菜单。
- Windows 独立 Git 源码目录支持控制台「系统 → 应用更新 → 安装并重启」；只安装官方稳定版标签，要求源码无未提交修改且分支可快进，失败时尝试恢复原提交。
- 源码更新暂不可用时仍显示安装按钮，并说明原因。
- 修复首次切到手动模型时未提交供应商和模型、导致切换失败的问题。
- 将依赖真实配置、人格和模型的旧测试改为临时数据与本地模型服务，真实 DSH 内核仍参与验证。
- 打包与公开导出增加输出路径保护，公开包排除根目录的本机维护说明。

Windows 用户可使用完整便携包或控制台应用更新。旧版源码安装需先手动更新一次；更新前保留本机修改。更新保留配置、人格、记忆与表情库。

本地完整回归 51 组全部通过，使用独立源码目录、固定 DSH `0.2.0-rc.2` 内核、本地模型服务及临时浏览器资料目录。托盘测试覆盖深浅色、缩放、慢速探测时的点击、窗口切换和弹层隐藏；实际 Explorer 托盘溢出窗口仍需人工验收。本次未运行真实 QQ 收发、Docker 容器或 Electron 桌面端测试。
