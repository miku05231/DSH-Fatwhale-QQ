## QQ-DSH v0.2.5

- 新增可配置会话窗口：在「系统 → 行为设置 → 新建会话间隔（分钟）」自由设置，默认 180 分钟，0 表示持续复用。
- 从首次实际对话开始计时，窗口内续聊使用同一会话，到期后的下一次对话才新建；持续聊天不会延长起点。保存后下一条消息生效，重启桥接保留计时起点。
- 修复新版 DSH Desktop 连伴续聊时错误新建会话的问题；兼容不同宿主的恢复接口，旧会话映射和历史挂载继续可用。
- 群聊、私聊、发送人与权限范围继续隔离；普通成员不会进入管理员会话。受限权限的 headless 管理员模式仍按安全要求每轮新建。
- 将群记忆源码及测试中来源未确认的账号、昵称样例替换为明确的合成数据。
- 包含此前已提交的 Docker 部署修复与公开导出检查改进。

### 升级

Windows 用户使用完整便携包或控制台应用更新，保留原有配置、会话、记忆与表情库。
更新连伴代码后重启 DSH 一次；之后仅调整会话间隔无需重启。
源码用户更新到本版本，Docker 用户重新构建镜像。

### 验证

已使用隔离目录和本地假模型完成真实 Desktop 12 项、Web 与浏览器 10 项验证，
覆盖自定义 7 分钟、默认 179/180 分钟边界及实际续聊与新窗口。边界通过可控时间加速。
会话窗口另经桥接、设置 API、权限隔离与重启回归测试，并已完成 DeepSeek 独立复核。
发布流程还会执行 Linux / Windows 检查与实际便携包的隔离升级验证。

本版本替换当前源码及新发布包中的上述样例，不改写旧版本历史或既有发布附件。
