# QQ-DSH v0.2.9

- 控制台「系统 → 应用更新」支持检查正式版本；Windows 便携版和符合条件的独立 Git 源码目录可点击「安装并重启」，保留配置、人格、记忆、表情库与自定义工具。
- 源码更新仅安装官方稳定版标签，核对版本与提交，只允许当前分支快进；无法安装时保留按钮并显示原因。
- 托盘后台状态查询异步初始化并复用工作池，慢查询期间仍可响应点击；点击菜单外、切换窗口或收起托盘溢出面板时自动关闭菜单。
- 缩小托盘右键「退出」菜单，保留提示、无障碍说明和退出确认。
- 修复首次切到手动模型时未提交供应商和模型的问题。
- 修复 Windows 发布测试的文件锁与互斥锁就绪握手，直接检查隔离进程的就绪标记，并为冷启动的局部 PowerShell 检查提供独立时间预算。
- 测试进程超时会结束隔离进程树；清理失败时保留原始错误和测试报告。

更新入口：控制台右下角「系统」页面顶部的「应用更新 → 检查更新」。旧版源码安装需要先手动更新一次，才能使用源码自动安装功能。

v0.2.6、v0.2.7 和 v0.2.8 标签保留；这三个版本未通过全部 Windows 发布检查，没有正式发行包。

更新测试使用临时配置、人格、记忆和本地模型服务，并使用固定 DSH 内核验证兼容性。真实 QQ 收发、Docker、Electron 和实际 Explorer 托盘溢出面板不包含在此次发布的自动回归中。
