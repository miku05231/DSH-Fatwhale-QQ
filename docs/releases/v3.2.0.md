# QQ-DSH v3.2.0

v3.2.0 增加可选的 AstrBot 插件运行时、管理与授权边界，并改进 NAS 日志查看和持久调度适配。

> **测试状态：尚未完成全面测试。**本版没有完成真实 QQ 新适配投递、公开天气 API、真实模型供应商、从零安装或所有 AstrBot 插件的完整兼容验收。详细的匿名范围见 [v3.2.0 验收摘要](v3.2.0-verification.md)。遇到问题请到 [GitHub Issues](https://github.com/miku05231/DSH-Fatwhale-QQ/issues) 提交。

## AstrBot 插件运行时

- 控制台插件页提供 AstrBot 安装、配置、启停、日志查看和环境回退管理。
- Windows 使用独立 Python 运行时；NAS 可选启用独立 sidecar。AstrBot 和新安装的插件默认关闭。
- 群策略按群明确授权插件。群主或群管理员身份不会自动获得项目管理员权限。
- AstrBot AI 模式复用 DSH 当前模型配置，使用独立会话；只可访问获准的 AstrBot 插件工具，不继承 DSH 本机电脑操作工具。
- 仅安装可信插件。进程或容器隔离不是针对恶意 Python 代码的安全沙箱。

## 调度授权

- 普通提醒的恢复发送绑定创建者与原会话，当前兼容范围为 is_task=false；跨群和来源失效的发送会被拒绝。
- 天气每日推送仅开放锁定样本的 weather.daily 发送范围。管理员授权必须绑定指定插件和具体私聊或群聊目标，只允许纯文本，不授予模型、工具或其他目标权限；发送时重新检查插件、群策略与授权。
- 提醒“任务”功能不属于本版已验证的普通提醒范围。受控撤权场景使用旧回调探针，没有额外等待第二次原生定时器触发。

## NAS 日志

控制台可查看按日期归档的桥接日志，并从独立 NapCat 容器读取经过认证的实时日志。页面按需轮询，未获授权的请求会被拒绝。具体受控矩阵和边界见匿名验收摘要。

## 兼容与运行时

AstrBot 固定版本为 4.29.3，Python 运行时为 3.12.10。本版受控检查覆盖 Windows x64 与 NAS Linux amd64，不据此承诺其他操作系统、架构或全部 AstrBot 插件兼容。依赖的完整传递版本没有全部以哈希锁定。

DSH 0.2.1-rc.5 在 Windows 与 NAS 的受控兼容检查通过；生产 DSH 核心仍为 0.2.0-rc.2。该兼容检查使用受控模型协议，不是生产升级或真实模型供应商认证。

## 环境回退

AstrBot 回退恢复整代环境快照，可能同时恢复共享依赖、插件配置和插件数据。回退前需考虑快照之后写入的数据。

## 其他变更

- NAS 日志页支持日期日志与经过认证的 NapCat 日志源，减少对旧控制台日志回退的依赖。
- 更新器与控制台改进了运行状态、日志读取和调度授权检查；AstrBot 仍默认关闭。

部署和运行说明见 [AstrBot 插件说明](../astrbot.md)；项目其他公开指南见 [README](../../README.md)。
