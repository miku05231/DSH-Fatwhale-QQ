# QQ-DSH v0.2.7

- 缩小托盘右键「退出」菜单，保留完整提示、无障碍说明和退出确认。
- 状态查询使用异步打开并复用的后台工作池，避免冷启动准备和慢速查询阻塞托盘点击。
- 收起托盘溢出面板、点击菜单外或切换窗口时自动关闭菜单。
- Windows 独立 Git 源码目录支持控制台「系统 → 应用更新 → 安装并重启」；只安装官方稳定版标签，要求分支可快进、源码无未提交修改，并保护本机数据。
- 源码安装暂不可用时仍显示安装按钮和具体原因。
- 修复首次切到手动模型时未提交供应商和模型的问题。
- 旧测试改用隔离配置、临时人格与记忆、本地模型服务；真实 DSH 内核仍参与兼容性验证。
- 打包与公开导出增加输出路径保护，并排除本机维护文件。

控制台右下角「系统」页面顶部提供「应用更新 → 检查更新」。有新版且安装条件满足时，可点击「安装并重启」。旧版源码安装需要先手动更新一次，才能使用源码更新功能。更新保留配置、人格、记忆、表情库及自定义工具。

v0.2.6 标签保留，但该版本未通过 Windows 发布检查，也未发布正式发行包。本版修复其冷启动响应问题。

本机完整回归 51/51 组通过，使用固定 DSH 内核、本地模型及隔离浏览器。验证范围包括 Windows 深浅色与缩放、连续后台查询、查询阻塞及工作池初始化期间退出、前台窗口切换、模拟溢出面板隐藏，以及实际便携包的隔离安装。真实 QQ 收发、Docker、Electron 和实际 Explorer 托盘溢出面板未包含在自动回归中。
