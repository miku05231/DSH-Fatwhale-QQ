## 方法与限制

审计结合了全历史 Git 对象扫描、Gitleaks、人工上下文判读和图片检查。DeepSeek 复核只接收脱敏的类别与代码行为摘要，没有发送候选原值、个人邮箱、账号或私人端点。

覆盖范围不包括不可达对象、其他 PR 引用、分叉仓库、托管平台缓存和既有发布包。模式检测无法保证识别编码、拆分或未知格式的秘密；人工图片检查也不能代替完整的隐写分析。

结论是：本次在所述范围内未确认真实访问密钥泄漏，已修复当前导出器的隐私检查和日志问题；历史个人身份信息及未决标识仍需所有者决定如何处理。
