# 应用更新与发布

源码提交、版本标签与正式 Release 分别维护。客户端只检查官方仓库的稳定版 Release；提交到 main、修改 README 或上传单个 EXE 不会自动触发客户端升级。

## 用户升级

Windows 便携版在系统页检查更新，经确认后下载完整便携包，校验 `SHA256SUMS.txt`、版本与路径，备份程序文件，再替换并重启。保留本机配置、状态、日志、NapCat、人格、记忆、表情、工作区与自定义数据；数据放在程序文件位置导致冲突时会拒绝覆盖。

安装记录和回滚备份位于本机 `state/updates/`。失败后先检查结果，避免在更新过程中移动目录。只有启动器 EXE 不能补齐其它程序文件。

独立 Git 源码安装要求无未提交修改、可快进且没有其它 Git 操作。worktree、Docker、非 Windows、外部配置或自定义状态目录按界面说明手动更新。旧版 runtime 包兼容限制见 [v3.2.0](releases/v3.2.0.md#便携更新兼容)。

companion 随 `src/companion/` 更新；安装器不自动改写 DSH profile。完整 bundle 与旧 server-only 标记块的迁移见 [控制台使用](console.md)。

## 作者发布 v3.3.0

使用以公开 main 为基线的干净目录，只加入审过的程序、模板、测试和公开文档。不要从运行目录整体暂存；配置、账号标识、profile、日志、记忆、工作区、内部报告和备份都不能进入发布树。

发布前：

1. 核对根版本 `3.3.0` 与产品信息一致；companion 的独立版本不要求与主程序相同。部署以宿主 DSH／桥接插件为主，Docker 仅用于 NapCat，不要求发布桥接或 DSH 镜像。
2. 校对 [发行说明](releases/v3.3.0.md)、[验证记录](releases/v3.3.0-verification.md)、README 与图片。只有本候选实际执行的检查可写成通过。
3. 运行隔离测试、公开导出检查和打包／更新检查，确认升级保留用户数据。
4. 提交审过的公开文件；推送前复查暂存差异、远端 main 和明确的目标 ref。不要推送旧备份分支或批量标签。
5. 需要时先运行 `Windows Release` 的 `verify_only=true`，输入已推送提交的完整哈希，核对 Linux／Windows 检查与实际便携包安装结果。该操作仍会启动远端 Actions，应在发布授权范围内执行。

确认允许发布且上述检查通过后，在独立的公开发布 checkout 执行：

```powershell
git -c push.followTags=false push origin HEAD:refs/heads/main
git tag -a v3.3.0 -m "QQ-DSH 3.3.0"
git -c push.followTags=false push origin refs/tags/v3.3.0:refs/tags/v3.3.0
```

不要使用 `push --all`、`push --mirror` 或 `push --tags`。已有正式版本不覆盖；需要修正二进制时递增版本。

## 自动化与四个资产

`.github/workflows/release.yml` 响应版本标签，也支持手动运行。发布前核对稳定语义版本、标签与根 package.json；测试、构建、实际便携包隔离安装和资产检查通过后，读取同版本发行说明创建 Release。

| 资产 | 用途 |
| --- | --- |
| `qq-bridge-3.3.0-portable-win64.zip` | 完整 Windows 便携包及客户端更新 |
| `qq-bridge-3.3.0-source.zip` | 公开源码包 |
| `qq-bridge-launcher-3.3.0.exe` | 单独启动器 |
| `SHA256SUMS.txt` | 三项文件的 SHA-256 |

当前工作流固定 DSH `0.2.0-rc.2`，另行安排 `0.2.2-rc.1`／`0.2.1-rc.5` 兼容专项；源码的版本适配不自动改变 CI 内核。Linux DSH 检查不等于真实供应商验证。本版不安排桥接／DSH 的 Docker／NAS 构建、镜像发布或目标架构验收。

`verify_only=true` 会执行检查与构建但不创建 Release；默认值为 false。正常标签发布会写入 Release，不应用于仅供审阅的本地候选。

## 本机打包与检查

在干净源码副本执行：

```powershell
node tests/run-all.mjs --only 更新
node tests/run-all.mjs --only 封装应用
node tests/run-all.mjs --only 公开导出
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/make-release.ps1
node tests/release-update-test.mjs
```

产物位于 `dist/release/`。本机打包成功只证明这次构建成功，不替代 GitHub CI、从零安装或真实收发验收。

更新测试使用临时配置、假 Release 和隔离进程。不要针对正在运行的安装目录执行会写配置、启动协议端或安装更新的测试。

本版项目版本为 `3.3.0`，完整 companion 包为 `0.3.0`。发布前需确认 bundle 默认 `runMode: embedded`、启用自动连接、禁用／卸载后宿主存活，以及普通成员隔离聊天边界；旧 standalone 候选成绩不能替代新版验证。
