## 建议的人工验收顺序

1. 使用测试 QQ 账号，在已配置的私聊和白名单群检查明确唤醒、上下文续聊、普通群聊拒答及跨群隔离。
2. 开启回复语音，检查文字仍能收到、语音可播放，以及关闭 TTS 或断网时的文字回退。
3. 在 B站扫码登录后，配置一个来源、一个测试 QQ 目标，先手动检查，再验证一次短周期 Cron 和重复结果去重。
4. 检查生成内容与审计字段后，再由用户显式开启评论并确认人工验收；仅对本人控制或已获同意的测试动态验证一条评论和一次 @，随后检查审计与重复抑制。
