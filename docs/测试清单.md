# 测试清单与验收边界

本清单列出 v3.3 候选应执行的检查，不把旧版的绿色状态、开发环境截图或其他版本的计数沿用为当前结果。**当前提交、执行环境、实际结果和未测项目以 [v3.3.0 验证记录](releases/v3.3.0-verification.md) 为准。**

## 运行前准备

- 使用没有真实配置和用户数据的独立源码目录。测试只使用临时配置、独立 DSH_HOME/工作区、假 NapCat 和本机模型端点。
- 准备 Node.js 24、目标版本的 DSH 包和独立的 Edge/Chromium 浏览器资料目录；不连接日常使用的浏览器资料目录。
- `QQ_TEST_DSH_COMMAND` 指向已安装 DSH 的命令或 `lib/bin.js`，`QQ_TEST_DSH_VERSION` 必须与实际包版本一致。不要借 shim 意外回退到另一套 Desktop 依赖。
- 核心版本应分别验证 `0.2.0-rc.2`、`0.2.1-rc.5` 和 `0.2.2-rc.1`；某个版本通过不能推出其他版本通过。NAS 的 musl/CPU 架构需另验。
- 浏览器检查必须实际运行；跳过、启动失败或只验证 HTML 字符串都不能记为浏览器通过。

以下 PowerShell 示例从源码根执行。先把 DSH 入口替换为已安装目标版本的绝对路径；浏览器入口按本机安装位置设置。

```powershell
$env:QQ_TEST_DSH_COMMAND = '<DSH 包目录>/lib/bin.js'
$env:QQ_TEST_DSH_VERSION = '0.2.2-rc.1'
$env:QQ_TEST_REQUIRE_DSH = '1'
$env:QQ_TEST_BROWSER_EXE = Join-Path ${env:ProgramFiles(x86)} 'Microsoft/Edge/Application/msedge.exe'

node tests/run-all.mjs
```

全量运行器应汇总退出码、失败、超时与跳过，并保留隔离报告。不要因没有匹配到专项名称而把“运行 0 项”记为通过。需要测试其他目标版本时，切换入口和版本变量后重新记录结果。

### 浏览器验收要点

- 内嵌仅一个标题栏；主要按钮、快捷设置与约 6–8 行日志可见，900×560 和窄屏没有横向溢出。完整页仍保留九页和 `#memes → #stickers` 兼容入口。
- 启动、停止、重启只走 `/api/bridge/*`，以控制器回执决定按钮状态，不使用旧 ProcessControl 接口停止 DSH/NapCat。
- 人格切换失败回到已保存选择；模型草稿不被轮询覆盖，保存目标、待生效、实际应用与错误可区分；当前请求不被切换模型打断。
- 表情保存只写发送概率，保留整体启用与收集开关；已有小数值未编辑直接应用保持原值，0 只暂停自动发送。
- 日志可暂停跟随、复制和清空显示；清空后旧行不回填，新行继续出现，磁盘文件不被删除。
- iframe 高度消息必须核对精确的来源窗口与数值范围；其他页面发来的消息不能改变高度。
- 系统浏览器先完成一次授权再请求完整页 API；不得导出 DSH Cookie、泄露 grant，或接受任意打开 URL。

## 真实环境与人工验收

以下项目需要单独记录，不从模拟结果推断。真实账号的扫码/登录由用户完成；测试消息与联系人由用户明确选择或手动发送，测试工具不擅自投递。

| 场景 | 验收方式 | 通过证据与边界 |
| --- | --- | --- |
| 原生 DSH Desktop | 在真实 Electron 窗口打开插件、操作桥接、进入完整浏览器 | 页面正常、启停状态一致、DSH 存活；Edge 模拟 preload 不等于原生窗口验证 |
| DSH Web 完整 bundle | 真实 Web 宿主与独立浏览器资料目录 | 完整客户端加载、认证、iframe 请求与 bridge/controller 链路 |
| QQ 私聊/群聊文字 | 用户手动发送选定测试内容 | 关联收件、模型执行和发送结果，并取得接收方确认；不能仅以模型完成判送达 |
| 语音与图片 | 用户选择目标后单独验证 | 文本成功不代表 TTS/图片合成或发送成功；供应商失败单独记录 |
| NapCat 稳定性 | 长时运行、网络恢复和登录状态观察 | HTTP 可达不等于 QQ 在线；单次登录不保证免重新授权 |
| Docker 中的 NapCat | 核对宿主插件能连接已映射的 OneBot WebSocket，按实际环境检查登录和收发 | 容器部署由 NapCat 自身负责；本版不构建或验收桥接／DSH 容器镜像 |
| 从零安装/旧版升级 | 使用实际发行资产、新目录及保留的数据样本 | 安装器可用、可回滚、路径可迁移；源码测试不等于实际便携包安装通过 |

带真实供应商的验证只记录协议类型、所测版本与结果，不发布个人供应商清单、账号、聊天正文、群号、令牌或本机私人路径。截图使用隔离演示数据，真实日志不作为公开附件。
